# Search chat titles

In **Your chats**, search older chat titles for the selected native project. Results come from OpenCode's title search. This is not full-message, file-content or global cross-project search.

Search is bounded to 200 Unicode scalars and 800 UTF-8 bytes without control/format characters. Results page to a 2,000 chat limit; a broad result set asks you to narrow the query. Clearing the field cancels the query, and late results from an old query or project cannot replace the current results.

Loaded partial matches stay visible if a later page fails. Opening a result verifies its actual location before selection and does not silently attach draft text from another folder. Search terms go to the paired OpenCode server as part of the native request.

Owned Mac/NUC title-search checks and synthetic selection/race cases exist. Complete physical and release acceptance remains pending. See [chat actions](chat-actions.md), [migration](migrating-from-openwork.md) and [compatibility](opencode-compatibility.md).
