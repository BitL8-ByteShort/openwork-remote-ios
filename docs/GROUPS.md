# Local chat groups

Use a chat's Actions menu, long press or accessibility actions to move it into a local group. Groups organize chats for this PocketWork connection/project on this device. They do not create server groups, change a chat's folder or grant/restrict project access.

Removing a group keeps its chats. Renaming or deleting an actual chat is a separate native server action. Local group/default records use protected app storage and are removed by full local reset; they do not sync to OpenCode or another phone.

If the connection/project changes, close and reopen an action rather than carrying a stale target across it. See [chat actions](chat-actions.md), [migration](migrating-from-openwork.md) and [compatibility](opencode-compatibility.md). The current native candidate is not a distributed beta or App Store release.
