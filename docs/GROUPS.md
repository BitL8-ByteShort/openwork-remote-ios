# Local chat groups

Use a chat's Actions menu, long press or accessibility actions to move it into a local group. Groups organize chats for this PocketWork connection/project on this device. They do not create server groups, change a chat's folder or grant/restrict project access.

Removing a group keeps its chats. Renaming or deleting an actual chat is a separate native server action. Local group/default records use protected app storage and are removed by full local reset; they do not sync to OpenCode or another phone.

## Project archive in the source candidate

In Your chats, swipe a project row right and choose Archive. A long press or the Archive project accessibility action offers the same local operation. This hides the project on this device; it does not delete files/chats or archive anything on OpenCode.

Open Archived projects, then turn that project's visibility back on to restore it to the list. This opens the Visible projects settings, which also contains Show future projects. Visibility is a display preference, not an access restriction. These archive controls are in the next source candidate, not delivered build9.

If the connection/project changes, close and reopen an action rather than carrying a stale target across it. See [chat actions](chat-actions.md), [migration](migrating-from-openwork.md) and [compatibility](opencode-compatibility.md). The native integration is available in internal TestFlight1.0.0(9); public App Store release remains pending.
