# Repository artwork

`pocketwork-banner.svg` is the current original PocketWork banner for the OpenCode candidate. It uses the project's own mark and includes text alternatives. It contains no third-party logo, tracking or remote asset.

The older `banner.png`, `pair-again.jpg` and `rename-chat.jpg` belong to the earlier OpenWork beta. They are retained as development history and are not current native-release screenshots. The maintained README uses the new banner.
