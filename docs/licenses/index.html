Shipped libraries and artwork

No third-party SDK or external Swift package is bundled with the iOS client. The app uses Apple system frameworks, system fonts and SF Symbols. Its app icon and connection artwork are original project assets except for the credited OpenCode logo. OpenCode and OpenTunnel run separately and are not bundled in the iOS app. Earlier OpenWork compatibility code retained for local recovery or development does not make this release an OpenWork client.
