# Working-copy changes

Open **Changes** for the selected native project. The candidate reads OpenCode's VCS information, status and working diff. This includes edits made outside the current chat. It does not claim that the assistant made every change.

Choose a supported text file to inspect its patch. Binary, unavailable, oversized or unsupported changes hand off to the computer. Patch text is bounded per file and line previews disclose shortening. OpenCode returns a location's working diff as a batch, so selecting one file may transfer other diffs from that location.

The app has no initialize, stage, commit, revert or command-execution action in this view. A non-repository location has an explicit computer handoff. Reading changes does not broaden or revoke native server access.

Disposable Mac/NUC Git/non-repository checks cover Unicode paths, rename/binary status and working patches. Simulator views are checked separately. The complete native release and physical-device matrix remain pending. [Compatibility](opencode-compatibility.md) records the boundary.
