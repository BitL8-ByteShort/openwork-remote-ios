# Historical screenshots

The existing PNG files in this directory document earlier OpenWork beta flows. They are retained as dated development history and are not screenshots of, or qualification evidence for, the OpenCode migration candidate. Current maintained guides do not present them as native-release screenshots.

New App Store/TestFlight screenshots must come from the tested native candidate with synthetic data, correct iPhone/iPad layouts and no real pairing code, credential, private address, conversation or file path. Simulator captures, physical-device checks and distribution evidence remain distinct.
