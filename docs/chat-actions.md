# Chat actions

In **Your chats**, use the visible Actions menu, long press or accessibility actions. Rename changes the native chat title on the phone and computer. Blank titles are not saved. Cancel keeps the original title.

**Continue in a new chat** copies the settled conversation with the current model/settings and leaves the original intact. **Fork before this message** excludes that message and everything after it. Keep the source chat idle while copying; this is not an atomic snapshot against concurrent desktop changes.

**Delete** reviews the chat and every child branch in its native tree. The confirmation is permanent and includes descendants; a branch created during deletion may also be removed. Keep the tree idle. Host files remain. This is separate from removing a local group or resetting the phone.

A request already sent is not undone by closing its sheet. If the outcome is unconfirmed, inspect the actual state/recent chats and use the offered status checks. PocketWork does not automatically repeat it. Similar titles alone don't prove which action succeeded.

Owned create/rename/fork/tree-delete/title-search checks passed on Mac and NUC with unrelated session records preserved.
